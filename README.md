# GTF-Banking Complete Structure

Professional banking-style frontend structure with:
- Public banking website
- Customer online banking
- Separate administrator/manager console
- Responsive design system
- Backend-ready route architecture

Important:
- Financial values, customers, transactions, compliance decisions and staff permissions are intentionally not fabricated.
- Connect the existing Express/Supabase backend before treating dashboard data as live.
- Keep private/server credentials out of frontend files.
