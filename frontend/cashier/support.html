Quick operational guidance

Confirm the transaction status first and avoid submitting duplicate transactions. If the issue remains unresolved, submit a support request with the transaction reference.
Completed transactions should only be reversed through the authorized reversal workflow. Do not manually modify account balances from the browser.
Include the relevant transaction or account reference, approximate time, issue category and a clear description. Never include passwords, PINs or authentication codes.
Use urgent priority only when the issue requires immediate operational attention according to your organization's support procedures.
