Security

Access is controlled at every level.

Authentication identifies the user while authorization determines which portal and resources that user may access.

01

Authentication

Users authenticate through the configured identity system before accessing protected banking resources.

02

Profile & Role

The backend determines the user's trusted profile and assigned role rather than relying on browser-controlled values.

03

Portal Authorization

Customer, cashier and management areas remain separated according to authorized permissions.
