Frequently Asked Questions

Common manager support questions.

How do I report a transaction issue?

Create a support ticket using the Transaction category and include the transaction reference number and relevant account information.

How do I escalate an urgent issue?

Select Urgent priority and provide enough operational information for the support team to investigate the issue.

Can I track an existing ticket?

Yes. Existing tickets appear in the Support Tickets table with their current status.

What should I do about a security concern?

Select the Security category and describe the concern without including passwords, private keys or other sensitive credentials.
