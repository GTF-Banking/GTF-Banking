Security

Your security matters. We design the platform around practical protections, not exaggerated claims.

What we focus on

  • Authentication — Secure sign-in with protected sessions
  • Authorization — Role-based access enforced on the server
  • Data protection — Sensitive values masked in the UI; secrets never shipped to the browser
  • Auditability — Important administrative actions can be logged
  • Session control — Sign out and session expiry support

We do not claim that any system is 100% fraud-proof. Security is a continuous practice of good design, monitoring, and user awareness.

Practical tips

Use a unique password, sign out on shared devices, and review account activity regularly.

Report concerns

If you notice unexpected activity, contact support promptly through the help center.
